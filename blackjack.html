Hi-Lo card counting

Hi-Lo is the most widely used counting system. Every card is assigned a value. You keep a running count starting at 0, adding or subtracting as each card is seen.

CardsCount valueWhy
2, 3, 4, 5, 6+1Low cards removed — the shoe is now richer in high cards, which is good for you
7, 8, 90Neutral — no meaningful effect on shoe composition
10, J, Q, K, A−1High cards removed — the shoe is now weaker for the player
A full deck always counts back to 0 (twenty +1 cards, twenty −1 cards). That’s why the countdown drill secretly removes a few cards first.

True count

A running count of +6 means more with one deck left than with five. The true count normalizes for what’s left:

True count = running count ÷ decks remaining. Estimate decks remaining from the discard tray (six decks total, minus what’s been played), usually to the nearest half deck. This trainer compares the exact true count to each index.

Example: running count +7 with about 2.5 decks left → 7 ÷ 2.5 = 2.8 → true count +2.

Betting by the true count

Raise your bet when the true count climbs — that’s where your edge lives. The bet suggestion in Learning mode uses this ramp with a $10 unit.

Insurance

Insurance is a side bet that the dealer has blackjack. It pays 2:1, so it only makes money when more than a third of the unseen cards are tens — which happens around a true count of +3. Below that, always decline, even with your own blackjack.

At a real table

Bet spreading
Vary bets 1:12 max. Larger spreads are more profitable but draw pit boss attention. 1:8 is safer for casual play.
Wonging
Back-counting (watching, not playing) then entering only at high counts. Maximizes edge but attracts attention.
Speed
Practice until you can count a full deck in under 30 seconds. Casinos are designed to distract you.
Cancel pairs
Train your eye to cancel a high card with a low one (K + 5 = 0) instead of counting each card. The pairs drill builds exactly this.
Camouflage
Occasionally make a “bad” play at low counts. Talk to the dealer, tip occasionally — look like a tourist.
How to use this page
Start in Learning mode with the badges on. When the count checks stop surprising you, switch to Practice and see if your bankroll agrees.
